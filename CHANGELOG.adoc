= Changelog
:toc: left
:toc-title: Versions

All notable changes to `aloli-crystal/jawas` are documented
here. The format follows
https://keepachangelog.com/1.1.0/[Keep a Changelog] and
versioning follows https://semver.org/[SemVer]
(3-digit for creations, 4-digit for ports of Ruby gems).

== v0.3.0 — 2026-11-16

=== Added

* `jawas verify` (`v`): three-level check (`.sha256` checksum, archive
  decrypted and decompressed, complete content: `mysqldump`/`pg_dump`
  end marker, `PGDMP` header, SQLite `COMMIT;` or
  `PRAGMA integrity_check`); latest backup of each database or all
  (`-A`); exit code 2 on failure.
* `jawas restore` (`r`): dry-run by default, throw-away database
  `<db>_r<YYYYMMDDHHMM>` by default, selection by date (`-D`) or file
  (`-f`), target (`-t`), explicit overwrite (`-R`); MySQL/MariaDB,
  PostgreSQL (plain and custom), SQLite (atomic replacement).
* `-i/--identity`: age private key to read encrypted backups back.
* Safeguards: checksum checked before loading, throw-away database
  dropped when a restore fails, `_globals` refused (to replay by hand),
  missing key detected at dry-run time.

=== Changed

* External tool errors summarised to their error lines.

== v0.2.1 — 2026-11-16

=== Documentation

* README introductions updated (`age` encryption has shipped).
* `README.adoc` brought in line with the French version: full
  `[encryption]` example, storage layout, differences from
  automysqlbackup, development; `.age` naming in the layout.

== v0.2.0 — 2026-11-16

=== Added

* `age` encryption of backups (`[encryption]` section): after
  compression, to `age1…`, `ssh-ed25519` or `ssh-rsa` public keys
  (`recipients`) and/or an `age -R` file (`recipients_file`);
  `binary = "rage"` supported. `.age` extension, `.sha256` sum of the
  encrypted file.
* `jawas check` makes sure `age` accepts every recipient; `jawas list`
  flags encrypted backups; `jawas sample` template extended.

=== Changed

* The backup stream now chains several filters (compression then
  encryption); on failure only the most downstream filter is reported
  (no more misleading "Broken pipe").
* An `AGE-SECRET-KEY-…` private key put in the configuration by mistake
  is rejected.

== v0.1.0 — 2026-11-16

=== Added

* Shard created from
  https://github.com/aloli-crystal/shard-template[aloli-crystal/shard-template]
  (Crystal reimagining of automysqlbackup).
* MySQL/MariaDB, PostgreSQL (plain or `custom`, roles via `_globals`)
  and SQLite (hot `.backup` or SQL dump) engines.
* Validated TOML configuration (unknown keys rejected), XDG then
  `/etc/jawas` lookup; no clear-text password.
* Daily/weekly/monthly rotation through hard links, retention in days
  with a `keep_min` floor.
* Streaming compression: none, gzip, pigz, bzip2, xz, zstd.
* `.part` files + atomic rename, `.sha256` sidecars, 0600/0700
  permissions, `latest/` links.
* CLI `backup`, `prune`, `list`, `check`, `sample`, `help` (shorts
  b, p, l, c, s, h), dry-run by default and `--apply`.
* Lock, `pre`/`post` hooks, `last-run.json` report, exit codes
  0/1/2/3.
