  automysqlbackup, développement ; nommage `.age` dans l'arborescence.

== v0.2.0 — 2026-11-16

=== Ajouté

* Chiffrement `age` des sauvegardes (section `[encryption]`) : après la
  compression, vers des clés publiques `age1…`, `ssh-ed25519` ou
  `ssh-rsa` (`recipients`) et/ou un fichier au format `age -R`
  (`recipients_file`) ; `binary = "rage"` possible. Extension `.age`,
  somme `.sha256` du fichier chiffré.
* `jawas check` vérifie que `age` accepte chaque destinataire ; `jawas
  list` signale les sauvegardes chiffrées ; modèle `jawas sample`
  complété.

=== Modifié

* Le flux de sauvegarde chaîne désormais plusieurs filtres (compression
  puis chiffrement) ; en cas d'échec, seul le filtre le plus en aval est
  rapporté (plus de « Broken pipe » trompeur).
* Une clé privée `AGE-SECRET-KEY-…` placée par erreur dans la
  configuration est refusée.

== v0.1.0 — 2026-11-16

=== Ajouté

* Création du shard depuis
  https://github.com/aloli-crystal/shard-template[aloli-crystal/shard-template]
  (réinterprétation Crystal d'automysqlbackup).
* Moteurs MySQL/MariaDB, PostgreSQL (SQL ou `custom`, rôles via
  `_globals`) et SQLite (`.backup` à chaud ou dump SQL).
* Configuration TOML validée (clés inconnues refusées), recherche XDG
  puis `/etc/jawas` ; aucun mot de passe en clair.
* Rotation daily/weekly/monthly par liens physiques, rétention en jours
  avec plancher `keep_min`.
* Compression en flux : none, gzip, pigz, bzip2, xz, zstd.
* Fichiers `.part` + renommage atomique, `.sha256`, permissions
  0600/0700, liens `latest/`.
* CLI `backup`, `prune`, `list`, `check`, `sample`, `help` (raccourcis
  b, p, l, c, s, h), dry-run par défaut et `--apply`.
* Verrou, hooks `pre`/`post`, rapport `last-run.json`, codes de sortie
  0/1/2/3.
